# Whisper-асистент

Підказувач для онлайн-пар, співбесід і дзвінків на Windows. Програма слухає звук, що грає на комп'ютері (Zoom, Meet, Teams, YouTube), розпізнає мову через Whisper і, коли чує питання, одразу пише коротку відповідь, яку можна сказати вголос. Вікно маленьке й лежить поверх інших.

- Розпізнає англійську, українську та російську (список мов налаштовується).
- Поки людина говорить, показує живий текст. Репліку закінчує за справжньою паузою, а не за крапкою від Whisper, тож повільних мовців не рве на шматки й не відповідає на півпитання.
- Відповідає з урахуванням вашого профілю (`про_мене.md`) і ваших матеріалів (папка `знання`).
- Мікрофон не відкриває: записує лише те, що грає в навушниках або динаміках.

## Працює на будь-якому залізі

| Комп'ютер | Де розпізнається мова | Якість |
|---|---|---|
| Відеокарта NVIDIA | на відеокарті, модель `large-v3-turbo` | найкраща, живий текст кожну ~1 с |
| Вбудована графіка, AMD, ноутбук | у хмарі Groq, модель `whisper-large-v3-turbo` (безкоштовно, той самий ключ) | така сама, як на NVIDIA |
| Без ключа Groq або без інтернету | на процесорі, модель `small` | гірша й повільніша |

Програма сама визначає, що є на комп'ютері, налаштовувати нічого не треба. Якщо хмара не відповідає (немає інтернету або вичерпано ліміт), програма на хвилину переходить на процесор, а потім повертається в хмару.

## Встановлення

1. Встановіть **Python 3.10–3.12** з [python.org](https://www.python.org/downloads/). Під час встановлення поставте галочку **Add python.exe to PATH**.
2. Завантажте проєкт (зелена кнопка **Code → Download ZIP**) і розпакуйте його. Або виконайте `git clone`.
3. Запустіть **`1_встановити.bat`**. Він поставить бібліотеки, а якщо є NVIDIA, то й бібліотеки CUDA (~1,3 ГБ).
4. Отримайте **безкоштовний ключ Groq** на [console.groq.com/keys](https://console.groq.com/keys) (картка не потрібна, ключ починається з `gsk_`). Впишіть його в `config.json`:
   ```json
   "keys": { "groq": "gsk_ваш_ключ", "gemini": "", "openai": "" },
   ```
   Одного ключа Groq вистачає і для відповідей, і для розпізнавання в хмарі.
   Додатково можна вписати ключ Gemini ([aistudio.google.com/apikey](https://aistudio.google.com/apikey), теж безкоштовний). Тоді Gemini буде запасним, якщо Groq не відповість.
5. Впишіть своє ім'я в `config.json` → `"user_name"` і заповніть `про_мене.md`. Він з'явиться після першого запуску. Можна також скопіювати `про_мене.example.md`.
6. Запускайте **`2_запустити.bat`**.

`3_увімкнути_відеокарту.bat` потрібен лише тоді, коли NVIDIA поставили вже після встановлення.

## Як користуватися

- **Угорі зеленим** показано поточну відповідь, вона з'являється по словах. Нижче йдуть почуті фрази 🗣 і попередні відповіді 💬.
- **Модель** (другий рядок): Groq, Gemini або OpenAI. Перемикається на льоту, вибір зберігається. Праворуч видно запасну модель.
- **Режим**: `questions` — відповідати лише на питання, `all` — на кожну фразу, `manual` — тільки кнопкою.
- **Своє питання**: впишіть питання й натисніть Enter. Асистент пам'ятає попередні питання й відповіді, тож можна уточнювати («why?», «а чому?»).
- **Відповісти зараз** — відповісти на останню почуту фразу.
- **Пауза** — не слухати. **Оновити знання** — перечитати профіль і папку `знання` без перезапуску.
- Розмови зберігаються в `logs\`. Вимкнути це можна так: `"save_log": false`.

## Налаштування (`config.json`)

| Поле | Що робить |
|---|---|
| `user_name` | ваше ім'я: підказки пишуться від вашої особи |
| `keys` | ключі: `groq`, `gemini`, `openai` |
| `whisper_backend` | `auto` (за замовчуванням), `local` — лише на цьому ПК, `groq` — завжди в хмарі |
| `language` | `null` — мова визначається сама (з `languages`), `"en"` — завжди англійська, найточніше |
| `whisper_prompt` | терміни, які Whisper має писати правильно |
| `answer_instructions` | як відповідати, напр. «англійською, рівень B1–B2, під відповіддю переклад» |
| `reasoning_effort` | `low` — швидко, `medium` або `high` — розумніше, але повільніше |
| `partial_seconds` | як часто оновлювати живий текст (у хмарі за замовчуванням вимкнено через ліміт запитів) |
| `silence_seconds` | коротка пауза, після якої шматок іде на розпізнавання (0.6) |
| `turn_gap_seconds` | тиша, після якої репліка закінчена і можна відповідати (1.2 с); якщо відповідає зарано, збільште |
| `unfinished_gap_seconds` | те саме для обірваного речення («What do you think about…»), 2.5 с |
| `slow_speech_wps` | якщо мовець говорить повільніше за стільки слів/с, паузи чекаються довше (до ×1,8) |
| `min_rms` | поріг гучності (якщо реагує на тихий фон, поставте 0.01) |
| `output_device` | частина назви навушників або динаміків, якщо треба слухати не стандартний пристрій |

## Безкоштовні ліміти

- **Groq**, відповіді: близько 30 запитів на хвилину, 1000 на день. Коли ліміт вичерпано, відповідає запасна модель.
- **Groq**, розпізнавання: 20 запитів на хвилину, 2000 на день, до 8 годин аудіо на день. Цього вистачає приблизно на 2–3 години пар щодня.
- Безкоштовні сервіси можуть використовувати запити для навчання моделей. Не пишіть у профіль і знання нічого секретного.

## Конфіденційність

У git **не потрапляють**: `config.json` (ключі), `про_мене.md`, вміст папки `знання`, `logs`. Для нових користувачів у репозиторії лежать шаблони: `config.example.json` і `про_мене.example.md`.

## Структура проєкту

```
whisper_assistant.py     точка входу (запускає 2_запустити.bat)
assistant/
  system.py              Windows: IPv4 першим, DLL NVIDIA, soundcard, COM
  config.py              config.json, ключі, меню моделей
  textproc.py            питання? речення обірване? галюцинація Whisper?
  knowledge.py           профіль і папка «знання» (.docx, .pdf, .txt, .md)
  audio.py               запис звуку ПК і нарізка на фрази за паузами
  transcriber.py         Whisper: відеокарта, процесор або хмара Groq
  llm.py                 моделі відповідей і запасна модель
  pipeline.py            фонові потоки: звук → текст → репліки → відповіді
  app.py                 вікно програми
tests/                   автотести (без звуку, відеокарти й інтернету)
```

Тести запускаються так: `.venv\Scripts\python -m unittest discover tests`

## Як це працює

- Звук записується через WASAPI loopback у спільному режимі. Програма робить копію того, що грає, тому навушники працюють як завжди, а Bluetooth-гарнітура не перемикається в режим Hands-Free.
- Фрази відрізаються за паузами. Коли нічого не грає, Windows не віддає навіть тишу, тож програма підставляє її сама.
- Розпізнавання: [faster-whisper](https://github.com/SYSTRAN/faster-whisper) локально або Groq Speech-to-Text у хмарі.
- Відповіді: Groq, Gemini, OpenAI, Anthropic або Ollama. Якщо основна модель не відповіла, автоматично спрацьовує запасна.
